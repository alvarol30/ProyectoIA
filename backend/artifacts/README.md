# Artefactos del modelo

Esta carpeta recibirá los archivos generados por `scripts/train_resnet.py`:

- `resnet50.keras`
- `class_names.json`
- `metrics.json`

Los pesos `.keras` están excluidos de Git mediante `.gitignore`; acuerden un almacenamiento adecuado antes de compartir o desplegar el modelo.
